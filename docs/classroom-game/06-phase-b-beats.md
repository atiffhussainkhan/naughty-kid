# Slice 06 — Phase B beats

Player-facing requirements for Phase B of the combined classroom session: Game 2 beats 6–10, plus the merge lines that start this phase, order it, and end it. No new jokes, props, penalties, or recovery rules.

## 1. Scope

In scope:

- The moment Phase B starts, and the strict-teacher state the kids play against.
- Beats in written order: Whoopee Cushion Pathway, Reverse Homework Trick, Doodle Attack, Monster Talk Distraction, Silly String Finale.
- Every object, action, and success test those beats name.
- The gentle silly-string spray, the victory dance, and the spray targets as written.
- Exactly three hidden whoopee cushions.
- What can be set up at each beat, which written options exist, and what can be reset.

Out of scope:

- Phase A beats 1–5, except the confetti prize claim as the signal that Phase B starts.
- Phase A wake, freeze, and laugh penalties.
- Words on the secret note, dance steps, and any joke that Game 2 does not already write.
- How a failed beat sends kids back, when that beat does not say so.

## 3. Stages

Phase B is one phase with five beats, played in the order in REQ-06-009. “Set up” is what that beat places in the room. “Reset” is what the source allows the kids to try again. An empty reset means the beat has no written retry.

### Phase B opening

Set up:

- Same room, with Phase A props still present.
- Teacher standing as the strict teacher, pretending to be very strict.
- Kids at the back.
- Funny secret note.
- Target mailbox on the other side of the room.
- The carried teacher’s desk.

Options for what the strict teacher is doing:

- Standing facing the whiteboard.
- Typing on a computer.
- Reading a big book.

Reset: none written. Phase B does not return to Phase A.

### Beat 6 — Whoopee Cushion Pathway

Set up:

- Floor lined with cushions.
- Exactly three hidden whoopee cushions under three of those cushions.
- At least one safe cushion in the same lining.

Options: which three cushions hide a whoopee is hidden from the kids. The count is not an option. It stays three.

Reset: UNKNOWN. A wrong step makes a loud, funny noise. The beat does not say the kids go back, leave the cushion, or walk the lining again.

### Beat 7 — Reverse Homework Trick

Set up:

- One giant, oversized pair of clown sunglasses.
- The kids in a line that can pass that pair.

Options: none written.

Reset: UNKNOWN. A drop means that pass has not succeeded. The beat does not say where the pair returns or where the kids stand afterward.

### Beat 8 — Doodle Attack

Set up:

- The teacher turns to face the whiteboard.
- The teacher’s shadow on the wall.
- A flashlight for the kids.

Options for a successful drawing:

- A funny hat on the shadow.
- Giant ears on the shadow.

Reset: UNKNOWN. No failure result is written.

### Beat 9 — Monster Talk Distraction

Set up:

- One kid who can yell.
- The other kids, who can crawl.
- A deep, goofy monster voice.
- The teacher, who can turn to investigate a sound.

Options for the yelled phrase:

- “The broccoli has landed!” is written and qualifies.
- Any other phrase is UNKNOWN. None is added here.

Reset: UNKNOWN. No failure result is written.

### Beat 10 — Silly String Finale

Set up:

- The secret note at the target mailbox.
- Silly string.
- The teacher’s desk and the teacher’s shoes, as the two written targets.
- A victory dance.

Options for the gentle spray:

- The teacher’s desk.
- The teacher’s shoes.

Reset: none written. The finale ends Phase B. It is not described as a beat the kids retry.
